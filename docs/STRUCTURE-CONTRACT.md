# Контракт структуры проекта

Актуальный контракт на 13 октября 2026 года. Правила путей заданы в
`tools/structure-contract.json`; `npm run check:structure` проверяет дерево,
реестр кадров, ссылки и публикационный манифест. Проверка обязательна в
`npm test` и `npm run build`. При добавлении категории ресурсов изменяйте
контракт и этот документ вместе.

## Код и данные

| Путь | Ответственность |
| --- | --- |
| `src/app/` | Создание сессии и переходы состояний игры |
| `src/core/` | Ввод, время, звук, математика |
| `src/entities/` | Определения поведения сущностей |
| `src/systems/` | Бой, появление врагов, способности, прогрессия |
| `src/world/` | Арены, геометрия, навигация и население мира |
| `src/rendering/` | Загрузка изображений, анимация и Canvas |
| `src/ui/`, `src/pages/` | Интерфейс и точки входа страниц |
| `data/` | Игровые определения и первичные JSON анимаций |
| `styles/` | CSS |
| `tools/`, `tests/` | Генераторы, сборка и проверки |
| `previews/` | Локальные HTML/JS страницы просмотра |
| `docs/` | Технические документы |

В корне находятся три публикуемые HTML-страницы, README, техническая
документация и конфигурация проекта. Изображения и звук в коде, корне и
`previews/` запрещены: снимки проверок относятся к исходным материалам.

## Ресурсы

```text
assets/
├── runtime/
│   ├── characters/
│   │   ├── heroes/<id>/
│   │   ├── enemies/<id>/
│   │   └── civilians/<id>/
│   ├── world/
│   │   ├── village/
│   │   ├── lutetia/
│   │   └── scenery/                 # Общие декорации нескольких арен
│   ├── projectiles/
│   ├── effects/                     # Допустимая категория при появлении файлов
│   ├── ui/achievements/
│   └── audio/
│       ├── music/
│       └── sfx/
└── source/
    ├── references/audits/           # Скриншоты проверок
    └── ...                         # Исходные листы, промпты, варианты, метаданные
```

- Кадр персонажа: `characters/<group>/<id>/animations/<action>/<index>.png`.
  Группы: `heroes`, `enemies`, `civilians`; действия: `idle`, `walk`, `attack`,
  `hurt`, `death`. Портреты и существующие атласы находятся в папке персонажа.
  Общие римские атласы хранятся в `enemies/shared/`.
- Один персонаж использует одну папку; действия могут ссылаться на один кадр
  повторно (например, мирные жители используют кадры ходьбы для заглушек).
- Файлы конкретной карты находятся только в `world/<map>/`. Сейчас изображения
  карт лежат непосредственно в этих папках; вложенные `buildings/`, `ground/`
  из старого плана не являются действующим требованием.
- Изображения интерфейса находятся в `ui/`, значки достижений — только в
  `ui/achievements/`. Генератор создаёт один набор.
- Музыка, эффекты и их лицензии находятся в `audio/` внутри `assets/runtime/`.
- `assets/source/` никогда не публикуется. Альтернативный прежний набор значков
  сохранён в `assets/source/achievement-icons-alternate/`; игра использует
  перенесённый набор без изменения изображений.

`assets/runtime/` содержит ресурсы игры и локальных предпросмотров, включая
сохранённые резервные атласы. Публикуемый набор — строго подмножество из
`tools/publication-manifest.cjs`; наличие файла в runtime само по себе не
включает его в сайт.

## Источники истины

`data/animations/character-frames.json` задаёт пути кадров относительно
`assets/runtime/`. JS-представления и границы кадров генерируются средствами
`tools/generate-layouts.cjs`; вручную их не редактируют.

`runtime/` в корне — сгенерированные скрипты для `file://`, а
`assets/runtime/` — изображения и звук. Это разные назначения. Скрипты
пересоздаются через `npm run generate`. `_site/` — результат сборки,
его пересоздаёт `npm run build`; вручную исправлять файлы там нельзя.

## Результат аудита и исправления

Подтверждены и исправлены: отдельная папка Лютеции вне `world/`, звук и
иконки вне `assets/runtime/`, два варианта папки достижений, отдельное дерево
кадров вне папок персонажей, снимки визуальных проверок внутри `previews/`.
Обновлены загрузчики, определения, HTML preload, манифест публикации,
импортёры, генераторы, тестовые загрузчики и документация.

Предыдущий `PROJECT-STRUCTURE-AUDIT.md` описывает историческое состояние:
разделение `game.js`, переход к ES-модулям и явная сборка уже реализованы.
Он сохраняется как история решений, а не как параллельный контракт.

Для нового ресурса: выберите категорию, добавьте файл и ссылки, при необходимости
обновите манифест публикации, выполните `npm run generate`, `npm test`,
`npm run build`. Не создавайте копию по старому пути ради совместимости.
