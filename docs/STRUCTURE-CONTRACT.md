# Контракт структуры

Актуален для Utrace Survivors после миграции 15 октября 2026 года, слои — с 20 октября 2026 года. Машинные правила: tools/structure-contract.json; публикация: tools/active-assets.json.

| Путь                      | Назначение                                                                            |
| ------------------------- | ------------------------------------------------------------------------------------- |
| src/main.tsx, src/App.tsx | Единственная production-точка входа и навигация                                       |
| src/app                   | Композиционный корень сессии, состояние забега, переходы, представления для UI        |
| src/components            | Весь React-интерфейс: меню, экраны забега, HUD, модальные панели                      |
| src/core                  | Время, ввод, звук, пути ресурсов, наблюдаемый store, математика, подписки             |
| src/systems               | Игровая механика; src/systems/queries — чистые запросы к состоянию забега             |
| src/entities              | Реестры героев и врагов: данные юнитов вместе с их Canvas-артом                       |
| src/services              | Облако (Firebase): вход, позже прогресс и таблицы лидеров; без конфигурации выключено |
| src/world                 | Арены, геометрия и навигация                                                          |
| src/rendering             | Canvas, кадры, арт, пол арены, камера                                                 |
| src/ui                    | Портреты меню, бестиарий и предпросмотр противников                                   |
| data                      | Определения контента, реплик и таймингов анимаций                                     |
| styles                    | CSS и семантические токены                                                            |
| tools, tests              | Генераторы, проверка контрактов, тесты                                                |
| assets/runtime            | Поддерживаемый ресурсный каталог; публикация — только явное подмножество              |
| assets/source             | Авторские источники, вне публикации                                                   |
| docs                      | Действующие инструкции, аудит и помеченные исторические материалы                     |
| dist                      | Vite-результат; не хранится в Git                                                     |

В корне index.html и две совместимые ссылки-перенаправления. Старого компилятора file://, runtime-бандлов и отдельных HTML-приложений больше нет. Основной способ запуска — HTTP через Vite или статический сервер dist.

## Инварианты

- Ресурсы только в assets. Runtime-категории и имена проверяются check:structure; assets/source никогда не публикуется.
- Каждый ресурс из active-assets.json существует и копируется Vite в dist/assets/runtime с тем же относительным именем.
- Персонажи рисуются Canvas-кодом; старые реестры кадров и генераторы больше не используются.
- Реплики определены в data/enemies/phrases.js и проверяются на соответствие текущим ID противников.
- Производственные данные определяются в data. Добавление юнита обновляет данные, метаданные бестиария и поведенческие проверки; числовые характеристики не дублируются в текстах.
- Новые test\*.cjs подхватываются npm test автоматически. Нельзя исправлять падения общих механизмов отключением suites.
- Перед изменением формата сохранений нужна миграция; перед удалением ресурсов — проверка статических и динамических потребителей.

## Слои и разрешённые импорты

Порядок слоёв: `data → core → world → systems → services → rendering → entities → ui → app → components → src`
(src — точки входа main.tsx и App.tsx). Файл может импортировать только свой слой и слои, перечисленные
в его строке матрицы `layers` в tools/structure-contract.json. Проверяет `checkLayers` в
tools/check-structure.cjs (часть `npm test` и `npm run check:structure`), тест —
tests/test-structure-layers.cjs. Учитываются статические, `export … from`, `import type` и
динамические `import()` с относительным путём; пакеты (react, firebase) не проверяются.

| Слой            | Может импортировать                                                   |
| --------------- | --------------------------------------------------------------------- |
| data            | ничего вне data                                                       |
| core            | data                                                                  |
| world           | data, core                                                            |
| systems         | data, core, world                                                     |
| systems/queries | data, core, world (чистые вопросы к состоянию, без остальных systems) |
| services        | data, core, systems                                                   |
| rendering       | data, core, world, systems/queries                                    |
| entities        | data, core, world, systems/queries, rendering                         |
| ui              | data, core, world, systems, rendering, entities                       |
| app             | data, core, world, systems, services, rendering, entities, ui         |
| components      | всё, кроме src                                                        |
| src             | всё                                                                   |

Слой всегда видит свои подслои (systems → systems/queries). Новая папка в src без строки в матрице —
ошибка. Сообщение о нарушении называет файл, оба слоя и список разрешённого.

Правила, которые матрица не выражает:

- Симуляция не читает клавиатуру и настройки: core/input.js собирает намерение движения в
  `run.move` (клавиши, стрелки, стик) перед каждым шагом. Пока сессия спит за другой страницей,
  `input.disable()` выключает клавиатурные команды; страница вида (`body.dataset.view`) вводом не
  читается.
- То, что зависит от экрана (кто из врагов говорит), вызывается из сессии с видимым прямоугольником
  мира, а не из шага симуляции.
- Типы, которые app отдаёт React (Session, Account), живут в src/app/types.ts.

Осознанные исключения и долги:

- entities стоит после rendering: это реестры юнитов вместе с их артом. systems получают их только
  через внедрение (`enemies`, `heroes` в create), не импортом.
- ui — превью для React (бестиарий, портреты меню) и поэтому стоит на уровне app: ему нужны полные
  systems (расписание волн, узлы), а не только queries.
- Импорты уже чистые, но рисование ещё живёт в systems и world: `corpses.draw`, `abilities.draw`,
  `weapons.draw`, отладочный `collision.draw`. Их выносит этап 3 (рендер из систем).
