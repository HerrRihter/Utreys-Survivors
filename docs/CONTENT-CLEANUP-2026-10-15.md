# Реплики, палитра и очистка

Основные цвета героев и светлые заливки клиентов стали темнее. Контуры сохраняют неоновый стиль интерфейса.

## Как менять реплики

Откройте `data/enemies/phrases.js`, найдите ID нужного противника и отредактируйте список:

```js
multon: ['Отгрузка!', 'Меняем формат!', 'Соки ждут коды!'],
l3: ['Дубли!', 'Коды не сходятся!'],
```

Фразы до 48 символов. Пустой список `[]` отключает речь этого противника. Ключи совпадают с `data/enemies/units.js`. Вверху файла настройки в секундах: `duration` — время показа, `interval` — интервал между репликами на поле, `perEnemyCooldown` — минимальная пауза одного врага. По умолчанию это 2.8, 4.5 и 16 секунд. Убитые и невидимые враги не говорят; игровая пауза останавливает таймеры. Реплики не расходуют игровой генератор случайных чисел. В бестиарии реплики сменяются по очереди.

## Совместимость и удаление старого кода

- Валюта именуется `codes` во всём активном коде. Загрузка принимает `saved.codes ?? saved.helmets`; новое сохранение пишет только `codes`. Старое полученное достижение переносится без повторной выплаты.
- Аудио использует `utreys-audio`, автоматически читая `gaul-audio`, если нового ключа ещё нет. Приоритет у нового ключа; недоступность localStorage не ломает игру.
- Удалены механики fish/menhir и прежние расширения, город/деревня, их рендереры, реестры спрайтов, импортёры и генераторы. Геометрия и навигация арены сохранены в `src/world`.
- Тесты удалённых кадров заменены проверками текущих ресурсов и геометрии арены. Добавлены тесты реплик и миграции сохранений. Все найденные тесты запускаются без условных исключений.
- Исторические инструкции и отчёты перенесены в `docs/archive/legacy`. Текущие инструкции больше не требуют `npm run generate`.
- Исходная страница предпросмотра называется `arena-preview.html`; сборка также создаёт совместимый адрес `village-preview.html`.

Проверки: `npm run check` и `npm run test:browser` (после сборки).
