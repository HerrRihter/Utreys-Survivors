# Техническая документация

## Запуск

Для локальной разработки установите зависимости и запустите сервер:

```powershell
npm.cmd install
npm.cmd run dev
```

Также можно открыть `index.html` напрямую. Для этого режима обновляйте сгенерированные файловые бандлы командой `npm.cmd run generate`.

## Проверки и сборка

```powershell
npm.cmd test
npm.cmd run check:structure
npm.cmd run check:contracts
npm.cmd run build
```

Вариант игры использует общие системы управления, сражений, улучшений, сохранений и настроек. Игровой контент ограничен одним временным персонажем и пустой ареной.
